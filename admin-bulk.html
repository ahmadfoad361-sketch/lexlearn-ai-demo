إنشاء حسابات مجموعة كاملة

تسجيل الطلاب من ملف أو إدخال يدوي، مع مراجعة كل اسم قبل التنفيذ وتسليم بيانات الدخول في ملفات PDF منفصلة.

راجع بيانات المجموعة الأكاديمية قبل إنشاء الحسابات. لا تُملأ القيم الناقصة بافتراضات تلقائية.

1. إدخال الأسماء

ألصق أسماء الطلاب، كل اسم في سطر، أو ملف CSV يتضمن الأعمدة name وusername. يمكن أيضًا اختيار PDF أو صورة؛ راجع نتائج القراءة قبل إنشاء أي حساب.

الملفات تُقرأ داخل المتصفح، ولا تُرسل صور الأسماء إلى قاعدة بيانات LexLearn. تتطلب قراءة الصور تحميل مكتبة OCR، وقد تتطلب اتصالًا بالإنترنت.

2. مراجعة وإقرار البيانات

يمكنك تعديل الأسماء وأسماء الدخول قبل الإنشاء. تظهر بيانات المجموعة الأكاديمية للمراجعة ويمكن استكمال الناقص منها يدويًا. لا تعتمد معلومات غير صحيحة.

3. تسليم ملفات المجموعة

كل طالب يحصل على PDF خاص باسمه واسم الدخول وكلمة المرور الأولى وشعار LexLearn. تُنشأ أيضًا قائمة عامة بالأسماء والمجموعة والأستاذ دون كلمات مرور.

تنبيه: ملف ZIP يحتوي كلمات مرور أولية صريحة. احتفظ به في مكان آمن، ولا ترسله في مجموعة واتساب أو بريد جماعي. تظهر كلمات المرور بعد الإنشاء في هذه الجلسة فقط ولا تُحفظ في المتصفح أو سجلات LexLearn.
