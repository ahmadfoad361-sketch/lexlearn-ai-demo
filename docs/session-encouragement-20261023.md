# Attributed session completion screen

After server-confirmed completion of each of the 30 sessions, show a quiet branded screen with a study message, author/team, university affiliation, publication year and source link. It closes automatically after eight seconds and can be skipped immediately. The same message stays in the saved session report; reopening an old report does not replay the screen. Source and phrase selection are stable for a session, with nine lines rotating across the course. No scores or learning mastery are inferred by this feature.

All messages are original editorial paraphrases, explicitly labelled as simplified research-based messages rather than verbatim quotations. They summarize findings in the cited studies; they do not assert that the studies tested these particular motivational screens or proved LexLearn's effectiveness.

Verified sources:
- Roediger & Karpicke (2006), Washington University in St. Louis. Test-enhanced learning: taking memory tests improves long-term retention. https://pubmed.ncbi.nlm.nih.gov/16507066/
- Karpicke & Blunt (2011), Purdue University. Retrieval practice produces more learning than elaborative studying with concept mapping. https://pubmed.ncbi.nlm.nih.gov/21252317/
- Dunlosky, Rawson, Marsh, Nathan & Willingham (2013), Kent State, Duke, Wisconsin–Madison and Virginia universities. Improving Students' Learning With Effective Learning Techniques. https://doi.org/10.1177/1529100612453266

Checks cover all sessions and both languages, saved completion before display, no display on failed submission, no replay on report reload, timer/skip/focus handling, disabled storage and unsupported dialogs. Reduced motion removes animation, while the message remains available inline.
