# Learner design and automatic legal assessment

The conference page, its styles, dimensions and existing promotion block are preserved. Seventeen learner routes share an independent light/dark preference. The sign-in illustration reuses the existing student-library image. The portal and training path foreground the next saved session; reading, questions, feedback and results use distinct consistent surfaces. Results recommend recall or explanation practice from supported session scores.

Every free-response training grade now has a draft from gpt-5.4-mini and automated verification by gpt-5.4 with medium reasoning. The verifier receives the approved rubric, immutable answer, full original Arabic provisions and the draft; it returns the complete corrected assessment. Only validated final output is stored as a score. The diagnostic also uses two automated passes against the complete statutory text. If the account rejects access to gpt-5.4 with HTTP 403/404, the authenticated grading operation uses gpt-5.4-mini instead; training records the actual verifier model. No paid startup health probes are deployed. Ordinary wrong answers are corrected automatically; genuinely unresolved evidence or provider failure remains unscored with retry where supported. Instructor role is monitoring; no routine teacher approval is required. Percentages remain practice results, not university grades or validated cognitive measurements.

Two model calls per completed assessment increase latency and API cost. Existing request budgets remain in place, and completed versioned assessments are cached. Training upgrades v2/v3 results on session reopening. No credentials, permissions, consent flow, academic rubric or student answer is changed.
